# PoliTech · Portfólio de estágio

Site estático de Leonardo Dutra da Cruz para a avaliação bimestral de Engenharia de Software da UniFil. Abra `index.html` para consultar a cópia local. Os diagramas, as capturas, o vídeo e o relatório usam caminhos relativos ao site.

## Publicação no GitHub Pages

1. Envie o conteúdo desta pasta, incluindo o arquivo `.nojekyll`, para a raiz da branch `main` de um repositório do portfólio.
2. Em **Settings → Pages**, selecione **Deploy from a branch** e salve **main → / (root)**.
3. Aguarde a implantação e use a URL exibida em **Settings → Pages**.
